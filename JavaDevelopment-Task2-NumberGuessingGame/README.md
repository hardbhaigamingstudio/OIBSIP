Number Guessing Game (Java Swing)

Description:
This project is a GUI-based Number Guessing Game developed using Java Swing. The application generates a random number and allows the player to guess it within a limited number of attempts. The game provides hints after each guess and tracks the player's performance across multiple rounds.

Features:

* Random number generation
* GUI built with Java Swing
* Too High / Too Low / Correct hints
* Attempt counter
* Maximum attempt limit
* Win and loss conditions
* Play Again functionality
* Score tracking across rounds
* Difficulty levels:

  * Easy (1-50, 10 attempts)
  * Medium (1-100, 7 attempts)
  * Hard (1-200, 5 attempts)

Technologies Used:

* Java
* Java Swing
* Random Class
* ArrayList

How to Run:

1. Compile the source file:
   javac NumberGuessingGameGUI.java

2. Run the program:
   java NumberGuessingGameGUI
