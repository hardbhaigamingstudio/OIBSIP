The ATM Interface is a console-based Java application developed using Object-Oriented Programming principles. The system allows users to log in using a User ID and PIN, perform banking operations such as deposits, withdrawals, transfers, and view transaction history. The application validates account balances before withdrawals and transfers, stores all transactions in an ArrayList, and provides a secure login mechanism with a maximum of three attempts. The project demonstrates core Java concepts including classes, objects, encapsulation, collections, and menu-driven programming.
